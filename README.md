# EventPlanner AI

## שם הפרויקט
**EventPlanner AI – עוזר חכם לתכנון אירועים עם בובות מתנפחות**

## תיאור הפרויקט
EventPlanner AI היא אפליקציית Web מבוססת בינה מלאכותית שמטרתה לעזור לעסקי אירועים וללקוחות לבחור חבילת אירוע מתאימה בצורה מהירה, מקצועית ומבוססת מידע.

### איזו בעיה האפליקציה פותרת?
בעולם האירועים יש הרבה פרטים שצריך לבדוק לפני שסוגרים אירוע: סוג האירוע, מספר אורחים, מיקום, כניסה לאולם, מדרגות, גובה תקרה, חשמל, תיאום עם DJ, מזג אוויר באירועי חוץ, מחיר, מקדמה וזמינות ציוד. לקוחות רבים לא יודעים מראש מה לשאול, ואיש המכירות עלול לשכוח פרטים חשובים בזמן שיחה.

האפליקציה מרכזת את המידע העסקי במקום אחד, מאפשרת שיחה טבעית עם עוזר AI, מנתחת תמונה של מקום האירוע, מחפשת מידע מתוך בסיס ידע פנימי, ויכולה להפוך תשובה כתובה לקובץ שמע.

### קהל היעד
- בעלי עסקים בתחום האירועים
- אנשי מכירות שרוצים תשובות מהירות ואחידות ללקוחות
- לקוחות שמתכננים חתונה, בר מצווה, יום הולדת, אירוע חברה או אירוע ספורט
- צוותי תפעול שרוצים צ'ק ליסט ברור לפני אירוע

### כיצד נעשה שימוש בבינה מלאכותית?
האפליקציה משתמשת ב־OpenAI כדי:
1. לנהל שיחה טבעית עם המשתמש בעברית.
2. לנתח תמונות של אולם, כניסה, רחבה או צילום מסך.
3. לשלוף מידע מתוך בסיס ידע מותאם אישית בעזרת RAG.
4. ליצור קובץ שמע MP3 מתוך תשובת העוזר.

## יכולות עיקריות

### 1. Conversational AI
המשתמש יכול לשאול שאלות בשפה טבעית ולקבל תשובות מקצועיות בעברית.

דוגמה:

```text
איזו חבילה מתאימה לבר מצווה באולם עם 150 אורחים ומה חשוב לבדוק לפני האירוע?
```

המימוש נמצא בקבצים:
- `app.py`
- `src/openai_utils.py`

היכולת ממומשת באמצעות **OpenAI Responses API**.

### 2. יכולת מולטימודלית – Vision Input
המשתמש יכול להעלות תמונה של אולם, כניסה, רחבה, הזמנה או צילום מסך. המערכת מנתחת את התמונה ומחזירה תובנות לוגיסטיות ועסקיות.

המערכת יכולה לזהות ולנתח:
- מעבר צר או מדרגות
- גובה תקרה משוער
- מכשולים ברחבה
- התאמה להפעלת בובות מתנפחות
- נקודות שצריך לבדוק מול הלקוח לפני סגירה

המימוש נמצא בקובץ:
- `src/openai_utils.py`

### 3. RAG – Retrieval-Augmented Generation
האפליקציה כוללת בסיס ידע מותאם אישית בתיקיית `knowledge_base`.

בסיס הידע כולל:
- חבילות שירות
- מחירים וכללי מכירה
- צ'ק ליסט תפעולי
- שאלות נפוצות
- תסריטי מכירה וסגירה
- הנחיות בטיחות ולוגיסטיקה

כאשר המשתמש שואל שאלה, המערכת:
1. יוצרת embedding לשאלה באמצעות OpenAI Embeddings API.
2. מחפשת קטעים רלוונטיים ב־ChromaDB.
3. משלבת את ההקשר שנמצא בתשובת ה־AI.
4. מציגה למשתמש גם את המקורות שנשלפו.

המימוש נמצא בקובץ:
- `src/rag.py`

### 4. יכולת OpenAI נוספת – Text-to-Speech
לאחר קבלת תשובה, המשתמש יכול ליצור קובץ MP3 מהתשובה.

שימושים אפשריים:
- הכנת הודעה קולית ללקוח
- הקראת סיכום פנימי לאיש מכירות
- יצירת תסריט מכירה מוקלט

המימוש נמצא בקובץ:
- `src/tts.py`

## הוראות התקנה

### 1. הורדת הפרויקט
הורידו את הקבצים או שכפלו את המאגר מ־GitHub.

```bash
git clone <your-github-repository-url>
cd EventPlannerAI_Final_Project
```

### 2. יצירת סביבת עבודה
מומלץ ליצור סביבת Python נקייה:

```bash
python -m venv .venv
```

הפעלת הסביבה ב־Windows:

```bash
.venv\Scripts\activate
```

הפעלת הסביבה ב־Mac/Linux:

```bash
source .venv/bin/activate
```

### 3. התקנת ספריות

```bash
pip install -r requirements.txt
```

### 4. הגדרת משתני סביבה
צרו קובץ בשם `.env` בתיקיית הפרויקט לפי הדוגמה `.env.example`:

```env
OPENAI_API_KEY=your_api_key_here
CHAT_MODEL=gpt-4.1-mini
VISION_MODEL=gpt-4.1-mini
EMBEDDING_MODEL=text-embedding-3-small
TTS_MODEL=gpt-4o-mini-tts
TTS_VOICE=alloy
```

> חשוב מאוד: אין להעלות את קובץ `.env` או מפתח API אמיתי ל־GitHub.

### 5. בדיקת הפרויקט לפני הרצה

```bash
python scripts/verify_project.py
```

הבדיקה מוודאת שקבצי ההגשה קיימים, שאין `.env`, שאין תיקיות cache, ושהקוד עובר בדיקת syntax בסיסית.

### 6. הרצת האפליקציה

```bash
streamlit run app.py
```

לאחר ההרצה ייפתח דפדפן עם ממשק האפליקציה.

## הוראות הדגמה

### הדגמה 1 – שיחה רגילה
כתבו:

```text
איזו חבילה מתאימה לבר מצווה באולם עם 150 אורחים ומה חשוב לבדוק לפני האירוע?
```

מה צפוי לקרות:
המערכת תענה בעברית, תמליץ על חבילה מתאימה ותציין בדיקות חשובות לפני האירוע.

### הדגמה 2 – שאלת RAG
ודאו שהאפשרות "השתמש בבסיס ידע RAG" מסומנת וכתבו:

```text
מה מדיניות המקדמה ומה צריך לבדוק לפני אירוע חוץ?
```

מה צפוי לקרות:
המערכת תחפש מידע מתוך `knowledge_base`, תשלוף קטעים רלוונטיים מ־ChromaDB, ותשלב אותם בתשובה.

### הדגמה 3 – העלאת תמונה
העלו את הקובץ:

```text
sample_inputs/sample_event_venue.png
```

ובקשו:

```text
בדוק האם המקום מתאים לבובות מתנפחות ותן המלצות לוגיסטיות ועסקיות
```

מה צפוי לקרות:
המערכת תנתח את התמונה ותציין נקודות כמו מעבר, מדרגות, תקרה, מכשולים, חשמל והתאמה לפעילות.

### הדגמה 4 – שילוב תמונה + RAG
לאחר ניתוח התמונה, שאלו:

```text
בהתבסס על התמונה ועל בסיס הידע, איזו חבילה כדאי להציע ללקוח ומה צריך לבדוק לפני סגירה?
```

מה צפוי לקרות:
המערכת תשלב את ניתוח התמונה עם מידע מבסיס הידע ותיתן המלצה אחת מלאה.

### הדגמה 5 – Text-to-Speech
לאחר קבלת תשובת AI, לחצו על:

```text
צור קובץ שמע מהתשובה
```

האפליקציה תיצור קובץ MP3 ותציג נגן שמע.
