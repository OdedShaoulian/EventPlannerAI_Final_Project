# Sample Inputs for Demo

This folder contains sample files that can be used during the live demo.

## sample_event_venue.png
A simple generated venue image for demonstrating Vision Input.

Suggested prompt:

```text
בדוק האם המקום מתאים לבובות מתנפחות ותן המלצות לוגיסטיות ועסקיות
```

The image is only a demo file. In a real use case, the user can upload a real venue photo, entrance photo, invitation, or screenshot.
