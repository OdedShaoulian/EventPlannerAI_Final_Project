# תסריט הדגמה חיה לפרויקט EventPlanner AI

## לפני שמתחילים
ודאו שהאפליקציה רצה עם הפקודה:

```bash
streamlit run app.py
```

ודאו שה־API Key מוגדר בקובץ `.env` מקומי בלבד, ושבסרטון לא רואים את המפתח.

## פתיחה קצרה
שלום, אנחנו מציגים את EventPlanner AI, אפליקציית Web מבוססת AI שעוזרת לתכנן אירועים עם בובות מתנפחות. האפליקציה משלבת ארבע יכולות מרכזיות: שיחה עם AI, ניתוח תמונות, RAG על בסיס ידע מותאם אישית, ו־Text-to-Speech.

## שלב 1 - שיחה עם ה־AI
בלשונית "שיחה + RAG" נכתוב:

```text
איזו חבילה מתאימה לבר מצווה באולם עם 150 אורחים ומה חשוב לבדוק לפני האירוע?
```

מה להגיד:
כאן אנחנו משתמשים ב־OpenAI Responses API כדי לאפשר שיחה טבעית עם העוזר. העוזר מחזיר תשובה בעברית וממליץ על חבילה לפי הצורך של הלקוח.

## שלב 2 - RAG
נסמן "השתמש בבסיס ידע RAG" ונשאל:

```text
מה מדיניות המקדמה ומה צריך לבדוק לפני אירוע חוץ?
```

מה להגיד:
כאן המערכת לא מסתמכת רק על ידע כללי. היא יוצרת embedding לשאלה, מחפשת ב־ChromaDB את הקטעים הכי רלוונטיים מתוך תיקיית `knowledge_base`, ואז משלבת את המידע בתשובה.

## שלב 3 - יכולת מולטימודלית
נעבור ללשונית "ניתוח תמונה" ונעלה את הקובץ:

```text
sample_inputs/sample_event_venue.png
```

נכתוב:

```text
בדוק האם המקום מתאים לבובות מתנפחות ותן המלצות לוגיסטיות ועסקיות
```

מה להגיד:
כאן אנחנו משתמשים ב־Vision Input דרך OpenAI Responses API. המערכת מנתחת את התמונה ומחזירה המלצות לוגיסטיות כמו מעבר, גובה תקרה, מכשולים, חשמל ותיאום עם DJ.

## שלב 4 - שילוב התמונה בתשובת הצ'אט
נחזור ללשונית "שיחה + RAG", נסמן "שלב את ניתוח התמונה" ונשאל:

```text
בהתבסס על התמונה ועל בסיס הידע, איזו חבילה כדאי להציע ללקוח ומה צריך לבדוק לפני סגירה?
```

מה להגיד:
כאן התשובה משלבת שלושה מקורות: שאלת המשתמש, בסיס הידע שנשלף ב־RAG, וניתוח התמונה.

## שלב 5 - יכולת נוספת Text-to-Speech
נעבור ללשונית "Text-to-Speech" ונלחץ על:

```text
צור קובץ שמע מהתשובה
```

מה להגיד:
זו היכולת הנוספת שבחרנו מעבר לדרישות החובה. המערכת הופכת את התשובה לקובץ MP3 שאפשר להשמיע או לשלוח.

## סיום
לסיכום, הפרויקט עומד בדרישות הקורס בכך שהוא כולל OpenAI Responses API, Embeddings API, Vision Input, ChromaDB, יכולת RAG, יכולת OpenAI נוספת של Text-to-Speech, וממשק Web ברור ב־Streamlit.
