# דוח ניקיון ושדרוג לפני הגשה

בוצעו הפעולות הבאות:

- נמחקו תיקיות `__pycache__` וקבצי `*.pyc`.
- נבדק שלא קיים קובץ `.env` עם מפתח API אמיתי בתוך הפרויקט.
- עודכן `.gitignore` כדי למנוע העלאת מפתחות, cache ותוצרי ריצה.
- שודרג `README.md` כך שהוא מכסה את כל סעיפי המרצה בצורה מפורשת.
- שודרג ממשק `app.py` ללשוניות ברורות: שיחה + RAG, תמונה, TTS והסבר לפרויקט.
- שודרג רכיב ה־RAG כך שהוא תומך בקבצי Markdown, TXT ו־PDF.
- נוספו קבצי ידע נוספים: `sales_scripts.md`, `safety_logistics.md`.
- נוסף קובץ תמונה לדמו: `sample_inputs/sample_event_venue.png`.
- נוספה מצגת מקצועית: `docs/EventPlannerAI_presentation.pptx`.
- נוסף קובץ שאלות ותשובות להגנה: `docs/DEFENSE_QA.md`.
- נוסף סקריפט בדיקה לפני העלאה: `scripts/verify_project.py`.

הערה: כדי להריץ ולהקליט דמו בפועל צריך להפעיל את האפליקציה מקומית עם מפתח OpenAI API תקין. אין להעלות את המפתח ל־GitHub.
