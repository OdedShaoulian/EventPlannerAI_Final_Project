# מדריך הקלטת דמו חי - EventPlanner AI

מטרת הסרטון: להראות בזמן אמת שכל דרישות הפרויקט עובדות: שיחה עם AI, מולטימודל, RAG ויכולת OpenAI נוספת.

משך מומלץ: 5 עד 10 דקות.

## לפני ההקלטה

1. לפתוח טרמינל בתיקיית הפרויקט.
2. ליצור קובץ `.env` מקומי בלבד לפי `.env.example`.
3. לוודא שהמפתח האמיתי לא נמצא ב־GitHub ולא מופיע בסרטון.
4. להריץ:

```bash
pip install -r requirements.txt
streamlit run app.py
```

5. לפתוח את האפליקציה בדפדפן.
6. להסתיר את ה־API Key בזמן ההקלטה.

## מבנה הסרטון המומלץ

### 1. פתיחה קצרה

להגיד:

שלום, אנחנו מציגים את EventPlanner AI, אפליקציית Web מבוססת AI שעוזרת לתכנן אירועים עם בובות מתנפחות. האפליקציה משלבת שיחה עם AI, ניתוח תמונה, RAG על בסיס ידע פנימי ויצירת קובץ שמע מתשובת העוזר.

### 2. שיחה רגילה עם AI

להקליד באפליקציה:

```text
איזו חבילה מתאימה לבר מצווה באולם עם 150 אורחים וכמה דברים חשוב לבדוק לפני האירוע?
```

להסביר בקצרה:

כאן אנחנו משתמשים ב־OpenAI Responses API כדי לקבל תשובה טבעית בעברית לפי בקשת המשתמש.

### 3. הדגמת RAG

לוודא שהאפשרות "השתמש בבסיס ידע RAG" מסומנת.

להקליד:

```text
מה מדיניות המקדמה ומה צריך לבדוק לפני אירוע חוץ?
```

להסביר:

כאן השאלה עוברת ל־OpenAI Embeddings API, המערכת מחפשת מידע רלוונטי בתוך ChromaDB, ואז התשובה נבנית לפי בסיס הידע שנמצא בתיקיית `knowledge_base`.

### 4. העלאת תמונה - מולטימודל

להעלות תמונה של אולם, כניסה לאולם, חלל אירוע או צילום מסך.

בשדה הבקשה לכתוב:

```text
בדוק האם המקום מתאים לבובות מתנפחות ותן המלצות לוגיסטיות ועסקיות
```

להסביר:

כאן האפליקציה משתמשת ב־Vision Input דרך OpenAI Responses API. המודל מנתח את התמונה ומחזיר תובנות כמו מעבר, גובה תקרה, מדרגות, מכשולים וחשמל.

### 5. שילוב ניתוח התמונה בתשובה

אחרי שהתקבל ניתוח תמונה, לסמן את האפשרות "שלב את ניתוח התמונה בתשובה" ולשאול:

```text
בהתבסס על התמונה ועל בסיס הידע, איזו חבילה כדאי להציע ללקוח ומה צריך לבדוק לפני סגירה?
```

להסביר:

כאן התשובה משלבת גם את המידע מהתמונה וגם את המידע שנשלף מתוך בסיס הידע.

### 6. יכולת OpenAI נוספת - Text-to-Speech

אחרי שמתקבלת תשובה, ללחוץ על:

```text
צור קובץ שמע מהתשובה
```

להשמיע כמה שניות מהקובץ.

להסביר:

זו היכולת הנוספת בפרויקט. האפליקציה הופכת תשובת טקסט לקובץ MP3 בעזרת OpenAI Text-to-Speech.

## משפט סיום מומלץ

לסיכום, הפרויקט עומד בדרישות הקורס בכך שהוא כולל Conversational AI, יכולת מולטימודלית, RAG עם OpenAI Embeddings ו־ChromaDB, וגם יכולת OpenAI נוספת של Text-to-Speech. בנוסף, יש ממשק Web ברור ב־Streamlit וקבצי README ו־requirements מסודרים להגשה דרך GitHub.
